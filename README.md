## Having trouble? 🤷

- Use `npm ci --prefix octofit-tracker/backend` and `npm ci --prefix octofit-tracker/frontend` to install dependencies.
- Verify MongoDB, Express, and Vite use ports `27017`, `8000`, and `5173`.
- Run the tier-specific contract tests before continuing to the next step.
